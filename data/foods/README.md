## Cách sử dụng

- Khi tính calo hàng ngày, **tra bảng này trước** — mỗi món đều có nguồn kèm link, đạt yêu cầu "không tự đoán calo".
- Món chưa có trong bảng → tra cứu web theo thứ tự ưu tiên nguồn trong CLAUDE.md, sau đó **bổ sung vào file nhóm tương ứng** để dùng lại lần sau.
- Món hoàn chỉnh (nhóm 7, 8) dao động lớn theo quán/khẩu phần → luôn dùng khoảng dao động, hỏi lại người dùng về size/khẩu phần nếu chưa rõ.
- Số liệu có dấu (*) hoặc ghi chú trong từng file là điểm dữ liệu nguồn lệch nhau — xem mục "Ghi chú" cuối mỗi file.
